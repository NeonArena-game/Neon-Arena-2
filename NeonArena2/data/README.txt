NEON ARENA 2 — PASTA DATA

Esta pasta pode guardar o backup portátil do jogo.

1. Abra http://localhost:8000/?save-data
2. Clique em "BAIXAR JSON".
3. Coloque o arquivo baixado nesta pasta.
4. Renomeie para:
   neon-arena-2-save.json
5. No computador/navegador de destino, abra a página ?save-data.
6. Clique em "CARREGAR DE data/".

O navegador não permite que o jogo grave arquivos diretamente nesta pasta. Por isso o backup é baixado e colocado nela manualmente.

IMPORTANTE: importar um backup substitui os valores salvos existentes quando as mesmas chaves forem encontradas. Faça outro backup antes de importar se quiser preservar o estado atual.
